# 종합 게임 기획 문서 — 《잿빛 왕관의 연대기 (Chronicle of the Ashen Crown)》

## 1. 프로젝트 개요
- **장르**: 클라이언트 온리(Client-Only) 솔로 2D 탑뷰 타일맵 액션 RPG
- **기술 스택**: C++17, `raylib`, `nlohmann/json` (단일 헤더), CMake
- **해상도 / 타일 규격**: 기본 창 `1280x720`, 타일 크기 `32x32` 픽셀 (월드 줌 2.0배 기본 카메라 렌더링)
- **데이터 드리븐 설계**: 모든 게임 스펙(플레이어, 아이템, 몬스터, 보스, NPC, 퀘스트, 맵, 타일, 아트 리소스)은 `data/` 하위 JSON 및 TXT 파일로부터 동적으로 로드하여 오브젝트를 생성한다.

---

## 2. 세계관 및 핵심 게임 루프
어둠에 잠식된 **잿빛 군주 말라코르**가 고대 성채 알현실을 점령하고 황야에 마물을 풀어놓았다.  
플레이어(왕국의 방랑 기사)는 **에쉬우드 마을(Town)**에서 퀘스트와 장비를 정비하고, **저주받은 황야(Field)**에서 마물을 토벌하며 성장한 뒤, **잿빛 성채 알현실(Boss Room)**에서 보스를 격파하고 **잿빛 왕관**을 되찾아야 한다.

### 코어 루프
1. **마을(Town)**: 촌장 엘드릭에게 퀘스트 수락 → 치유사 세라에게 회복 → 상인 마라에게 장비/포션 구매
2. **필드(Field)**: 8방향 이동 및 실시간 전투로 필드 몬스터 처치 → 골드·경험치 획득 및 퀘스트 진행
3. **성장**: 레벨업(최대 HP/ATK/DEF 상승) 및 마을 상점에서 상위 무기·방어구 구입 및 장착
4. **보스 룸(Boss Room)**: 잿빛 군주 말라코르의 2페이즈 패턴(장판·탄막·돌진)을 회피·공격하여 격파 → 엔딩 및 퀘스트 완료

## 3. 조작 및 플레이어 스펙 (`data/player.json`)

### 3.1 조작키
| 입력 | 기능 |
| :--- | :--- |
| `W / A / S / D` 또는 방향키 | **8방향 이동** (상/하/좌/우 + 4대각선, 대각선 속도 정규화) |
| `J` / `Space` / 마우스 좌클릭 | **기본 검격** (바라보는 8방향 전방 부채꼴 범위 공격 + 애니메이션) |
| `K` / 마우스 우클릭 | **회오리 베기 스킬** (360° 광역 공격, 공격력 1.8배, 쿨타임 4.0초) |
| `Left Shift` | **회피 대시** (바라보는 8방향 고속 이동, 0.25초 무적, 쿨타임 1.8초) |
| `E` | **상호작용** (NPC 대화/퀘스트 수락·완료/상점 열기/회복) |
| `1` / `2` | **퀵슬롯 포션 사용** (1: 체력 포션, 2: 상급 체력 포션) |
| `I` | **인벤토리 / 장비창 토글** |
| `Q` | **퀘스트 상세창 토글** |
| `ESC` | 열려 있는 UI 닫기 |

### 3.2 플레이어 초기 스펙 및 성장
- **초기 레벨**: 1 (최대 10)
- **초기 HP**: 120 (레벨업당 +25)
- **초기 공격력(ATK)**: 16 (레벨업당 +4)
- **초기 방어력(DEF)**: 4 (레벨업당 +2)
- **이동 속도**: 145 px/s (대시 시 400 px/s)
- **초기 소지금**: 60 Gold
- **필요 경험치**: `level * 100`
- **8방향 애니메이션 상태**: `IDLE`, `WALK`, `ATTACK` (각 8행 × 4프레임, 프레임 규격 48×48)

## 8. 소프트웨어 아키텍처 (싱글톤 통합 Manager 구조)
- **`GameManager` (Singleton + Facade)**: 프로그램 전체에 단 하나의 인스턴스만 존재하며, 모든 서브 매니저(`IManager` 구현체)를 소유하고 `Init → Update → Render → Shutdown` 생명주기를 통합 조율한다.
- **`IManager` (Abstract Base Class)**: `Init()`, `Update(float dt)`, `Render()`, `Shutdown()` 인터페이스를 정의하여 모든 매니저가 일관된 다형성 규약을 따른다.
- **서브 매니저 구성**:
  1. `ResourceManager`: `data/art_mapping.txt` 파싱 및 `Texture2D` 로딩/캐싱
  2. `DataManager`: `data/*.json` 파싱 및 스펙 데이터베이스 관리
  3. `MapManager`: `data/tiles.json` + `data/maps/*.txt` 파싱, 타일맵 렌더링, 충돌·워프 판정
  4. `EntityManager`: 플레이어(8방향 이동/애니메이션), NPC, 필드 몬스터, 보스 상태 관리
  5. `CombatManager`: 공격 히트박스, 스킬, 투사체, 보스 예고 장판, 데미지 텍스트/파티클 처리
  6. `QuestManager`: 퀘스트 상태 머신(`NotStarted → Active → ReadyToTurnIn → Completed`)
  7. `EconomyManager`: 골드, 인벤토리, 장비 스탯 합산, 상점 거래
  8. `UIManager`: HUD, 보스 HP 바, 대화창, 상점, 인벤토리, 퀘스트 트래커, 타이틀/승리 화면
