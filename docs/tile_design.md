# 타일 및 맵 데이터 설계 문서

## 1. 타일 규격 및 원칙
- **기본 타일 크기**: `32 × 32` px (탑뷰 2D 픽셀아트)
- **색상 팔레트 컨셉**: 중세 다크 판타지 — 마을은 따뜻한 석재와 녹지, 필드는 황량한 이끼 초원과 폐허, 보스 룸은 흑요석과 붉은 용암 대비.
- 모든 타일은 고유 정수 번호(`Tile ID: 0 ~ 15`)를 가지며, 속성은 `data/tiles.json`에 정의되고 텍스처 경로는 `data/art_mapping.txt`의 아트 ID(`1 ~ 16`)와 1:1 매핑된다.

## 3. TXT 맵 파일 나열 규칙 (`data/maps/*.txt`)

### 3.1 파일 포맷 규칙
1. **주석 라인**: `#`으로 시작하는 줄 및 빈 줄은 파서가 무시한다. 상단에 맵 이름·크기·범례 주석을 기록한다.
2. **행(Row) = Y좌표**: 위에서 아래로 `y = 0, 1, ..., Height - 1` 순서로 1줄에 1행을 기록한다.
3. **열(Column) = X좌표**: 왼쪽에서 오른쪽으로 `x = 0, 1, ..., Width - 1` 순서로 타일 번호를 **공백(Space)으로 구분**해 나열한다.
4. **가독성 정렬**: 두 자리 고정폭(`00` ~ `15`)으로 패딩해 텍스트 에디터에서 맵 지형을 직관적으로 확인할 수 있게 하며, 파서는 `std::stoi`로 앞자리 `0`을 자동 무시해 정수 타일 ID로 변환한다.

### 3.2 나열 예시 (5×4 미니 맵)
```text
# Map: example (5x4)
06 06 06 06 06
06 02 02 02 14
06 02 13 02 06
06 06 06 06 06
```
- 외곽(`06`: 나무)으로 이동 경계를 막고, 내부에 바닥(`02`: 석재 바닥), 중앙 오브젝트(`13`: 분수), 동쪽 출구(`14`: 이동 포탈)를 배치한다.

### 3.3 맵별 배치 설계
1. **`data/maps/town.txt` (`24 × 18`)**:
   - 외곽을 `06`(숲)으로 감싸고, 북쪽·서쪽·남쪽에 `08`(지붕)+`07`(벽) 형태의 마을 건물 3채 배치.
   - 중앙 광장(`02`: 석재 바닥) 한가운데 `13`(치유의 분수) 배치, 주변에 `12`(꽃밭)와 `01`(흙길) 연결.
   - 동쪽 출구 `(22, 8~9)`에 `14`(필드행 포탈) 배치.
2. **`data/maps/field.txt` (`32 × 24`)**:
   - 외곽 `06`(숲) 및 북부 성채 입구 `09`(흑요석 성벽).
   - 중앙을 가로지르는 `10`(강)과 2개의 `05`(나무 다리)로 동서/남북 구역 분리.
   - 서쪽 입구 `(1, 11~12)`에 `14`(마을 복귀 포탈), 북쪽 성채 입구 `(15~16, 1)`에 `15`(보스 룸 포탈) 배치.
   - 구역별 몬스터 서식지: 서부 초원(슬라임), 중부 흙길/폐허(고블린), 북부 성채 앞(해골 파수꾼).
3. **`data/maps/boss_room.txt` (`24 × 18`)**:
   - 외곽 전체 `09`(흑요석 성벽), 좌우 가장자리에 `11`(용암 구덩이) 배치.
   - 내부 `03`(성채 석판) 바닥과 남→북 중앙 `04`(알현실 붉은 카펫) 통로, 대칭 기둥(`09`) 4개 배치.
   - 남쪽 입구 `(11~12, 16)`에 `14`(필드 퇴각 포탈), 북쪽 왕좌 앞 `(11.5, 5)`에 보스 '잿빛 군주 말라코르' 배치.
